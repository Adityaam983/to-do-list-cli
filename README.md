# To-Do List CLI

Aplikasi To-Do List sederhana berbasis Command Line Interface menggunakan Python.

### Fitur
1. Tambah Tugas
2. Lihat Daftar Tugas  
3. Tandai Tugas Selesai
4. Data tersimpan otomatis di file tugas.json

### Cara Menjalankan
1. Pastikan sudah install Python 3
2. Jalankan: python to-do-list-cli.py
